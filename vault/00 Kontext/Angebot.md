# Angebot

> Entwurf – mit Skill `gastro-texte` (Abschnitt „Eigenes Angebot") ausformulieren.

## Leistung
- Moderne, handytaugliche Webseite (Startseite, Speisekarte, Öffnungszeiten, Kontakt/Anfahrt)
- Demo-Version zum Anschauen, bevor etwas kostet
- Übergabe-Dokument: alles gehört dem Kunden, jederzeit übertragbar

## Preise
- Erstellung (einmalig): CHF ___
- Änderungen nach Lancierung: CHF ___ pro Stunde / pauschal ___
- Laufende Kosten trägt der Kunde selbst: `.ch`-Domain ca. CHF 11 pro Jahr, Hosting gratis

## Ablauf
1. Gespräch + Kurz-Interview
2. Demo auf Vorschau-Link (fürs Handy)
3. Ja → Kunde registriert Domain auf seinen Namen → Seite geht live
4. Änderungen laufen über Vorschau → Freigabe → live
